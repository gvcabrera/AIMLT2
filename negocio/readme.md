# Casos Prácticos de Machine Learning Aplicado a Negocio

Este proyecto contiene dos casos de estudio orientados a la aplicación de Machine Learning para resolver problemas de negocio mediante procesos de análisis, selección de algoritmos, exploración de datos y construcción de modelos predictivos.
El proyecto fue realizado por **Giovanni Cabrera y Rolando de Jesús Pineda (Equipo G)** para resolver la tarea propuesta denominada ***"Clínica de Diagnóstico de Negocio" en el Bootcamp "AI Machine Learning Trainee 2"***

---
## Caso A - Predicción de Abandono de Clientes

Archivo:

`Caso A - Predicción de Abandono de Clientes.ipynb`

### Objetivo

Identificar clientes con mayor probabilidad de abandonar la aplicación digital de una institución financiera para permitir la ejecución de acciones de retención y fidelización.

### Tipo de problema

Clasificación binaria.

### Variable objetivo

`abandono`

Valores:

- Si
- No

### Actividades desarrolladas

- Definición del problema de negocio.
- Identificación de la variable objetivo.
- Selección de algoritmos candidatos.
- Exploración y visualización de datos.
- División de datos en entrenamiento y prueba.
- Entrenamiento de modelos de clasificación.
- Comparación de métricas de desempeño.
- Evaluación de riesgos, sesgos y consideraciones éticas.
- Recomendaciones de negocio basadas en los resultados obtenidos.

### Algoritmos utilizados

- Regresión Logística
- Random Forest

## Caso B - Predicción de Ventas Futuras

Archivo:

`Caso B – Predicción de ventas futuras.ipynb`

### Objetivo

Predecir las ventas futuras de una cadena de tiendas utilizando variables relacionadas con marketing, operación, inventario, entorno competitivo y condiciones económicas.

### Tipo de problema

Regresión.

### Variable objetivo

`monthly_sales`

Representa el monto estimado de ventas mensuales por tienda.

### Actividades desarrolladas

- Comprensión del problema de negocio.
- Identificación de variables predictoras.
- Exploración y análisis estadístico de datos.
- Visualización de tendencias y relaciones entre variables.
- Preparación de datos para modelado.
- Entrenamiento y comparación de modelos de regresión.
- Evaluación mediante métricas de error.
- Interpretación de resultados desde la perspectiva del negocio.
- Recomendaciones para la toma de decisiones comerciales.

### Aplicaciones de negocio

- Planificación comercial.
- Gestión de inventarios.
- Optimización de campañas de marketing.
- Forecasting de ingresos.
- Planeación operativa de tiendas.
