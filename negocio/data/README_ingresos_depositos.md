# Dataset Prediccion de Ingresos por Depositos

## Objetivo
Predecir los ingresos mensuales generados por depositos utilizando tecnicas de regresion.

## Variable objetivo (Y)
- ingresos_mensuales_depositos

## Variables independientes (X)
- campanas_marketing: cantidad de campañas ejecutadas.
- estacionalidad: mes del año.
- tasa_interes_ofertada: tasa promocional ofrecida.
- indice_competencia: intensidad competitiva del mercado.
- indice_macroeconomico: indicador agregado del entorno economico.
- depositos_historicos_promedio: promedio historico de depositos.
- nuevos_clientes_mes: clientes captados durante el mes.
- usuarios_activos_app: usuarios activos de la aplicacion.

## Tipo de problema
Regresion.

## Cantidad de registros
500

## Consideraciones
- Dataset sintetico para fines academicos.
- Sin nulos ni duplicados.
- Diseñado para ejercicios de regresion y prediccion de ingresos futuros.
